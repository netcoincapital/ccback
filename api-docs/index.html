🟢 API V2 — Non-Custodial (بدون UserID)

✅ معماری جدید Non-Custodial:
این endpointها عمومی هستند و نیازی به UserID ندارند.
داده‌ها از CoinGecko رایگان (۱ req/۲min) کش می‌شوند.
بار سرور برای ۱۰ تا ۱۰۰,۰۰۰ کاربر یکسان است.
هزینه اضافی: $0

GET قیمت لحظه‌ای

/api/v2/prices
دریافت قیمت لحظه‌ای همه ارزهای اصلی. داده از CoinGecko هر ۲ دقیقه کش می‌شود.

Query Parameters (اختیاری):

پارامترنوعتوضیحات
symbolstring اختیاریفیلتر بر اساس سمبل (مثلاً ?symbol=BTC)
currencystring اختیاریارز مرجع (پیش‌فرض: USD)
# 🔹 مثال — همه قیمت‌ها
GET https://coinceeper.com/api/v2/prices

# 🔹 مثال — قیمت بیت‌کوین
GET https://coinceeper.com/api/v2/prices?symbol=BTC

# 🔹 مثال — قیمت یک ارز خاص
GET https://coinceeper.com/api/v2/prices/BTC

GET نمودار قیمت (تاریخی)

/api/v2/chart?symbol=BTC&days=7
داده‌های قیمت تاریخی برای رسم نمودار. از CoinGecko هر ۵ دقیقه کش می‌شود.

Query Parameters:

پارامترنوعتوضیحات
symbolstring الزامیسمبل ارز (مثلاً BTC, ETH)
daysint اختیاریتعداد روز (۱ تا ۳۶۵، پیش‌فرض: ۷)
GET https://coinceeper.com/api/v2/chart?symbol=BTC&days=30

GET کارمزد شبکه‌ها (Gas Fee)

/api/v2/gas
کارمزد شبکه‌های مختلف از public RPC. هر ۱ دقیقه کش می‌شود.

Query Parameters (اختیاری):

پارامترنوعتوضیحات
chainstring اختیارینام شبکه (مثلاً ?chain=Ethereum)
# همه شبکه‌ها
GET https://coinceeper.com/api/v2/gas

# یک شبکه خاص
GET https://coinceeper.com/api/v2/gas?chain=Ethereum

GET لیست ارزها (صفحه‌بندی شده)

/api/v2/coins
لیست کامل ارزهای دیجیتال از CoinGecko. یکبار در روز کش می‌شود. با صفحه‌بندی برای کاهش حجم پاسخ و بهبود سرعت.

Query Parameters (اختیاری):

پارامترنوعتوضیحات
searchstring اختیاریجستجو در نام یا سمبل
pageint اختیاریشماره صفحه (پیش‌فرض: 1)
per_pageint اختیاریتعداد در هر صفحه (پیش‌فرض: 50، حداکثر: 200)
limitint منسوخاز per_page استفاده کنید
GET https://coinceeper.com/api/v2/coins?search=bitcoin&per_page=5

Response شامل متادیتای صفحه‌بندی:

{
  "success": true,
  "coins": [...],
  "count": 5,
  "page": 1,
  "per_page": 50,
  "total": 17408,
  "total_pages": 349,
  "has_next": true,
  "has_prev": false,
  "cache_status": "ready",
  "cache_age_seconds": 123.4
}

GET وضعیت سرویس

/api/v2/health
بررسی وضعیت همه کش‌ها و سلامت سرویس Non-Custodial.
GET https://coinceeper.com/api/v2/health
