# 📈 سیستم داده‌های تاریخی - 1 سال

## 🎯 **هدف:**
دریافت و ذخیره اطلاعات 1 سال گذشته همه کریپتوهای موجود در جدول `Currencies` برای امکان ساخت چارت‌های دقیق در بازه‌های زمانی مختلف.

## 📁 **فایل‌های ایجاد شده:**

### 1. **`historical_data_fetcher_1year.py`** (اصلی)
- **نقش:** دریافت اطلاعات 1 سال گذشته از API ها
- **منابع:** CoinMarketCap + CoinGecko (پشتیبان)
- **ویژگی‌ها:**
  - دریافت خودکار لیست ارزها از دیتابیس
  - پردازش batch برای عملکرد بهتر
  - مدیریت خطا و retry logic
  - آمار کامل عملیات

### 2. **`insert_24h_test_data.sql`** (تست فوری)
- **نقش:** 48 رکورد تست (24 BTC + 24 ETH)
- **کاربرد:** تست فوری امکان ساخت چارت
- **اجرا:** در phpMyAdmin یا command line

### 3. **`setup_database.py`** (راه‌اندازی)
- **نقش:** آماده‌سازی دیتابیس
- **عملکرد:** ایجاد ایندکس‌ها، بررسی ساختار

### 4. **`quick_historical_test.py`** (تست سریع)
- **نقش:** تست با 3 ارز مهم (BTC, ETH, BNB)
- **زمان:** ~5 دقیقه

## 🔧 **API های مورد استفاده:**

### **CoinMarketCap (اصلی):**
```
GET /v1/cryptocurrency/quotes/historical
Parameters:
- id: CMC_IDs (comma-separated)
- time_start: 1 year ago
- time_end: now
- interval: daily
- convert: USD
```

### **CoinGecko (پشتیبان):**
```
GET /coins/{id}/market_chart
Parameters:
- vs_currency: usd
- days: 365
- interval: daily
```

## 🛡️ **مدیریت خطا:**

### **Rate Limiting:**
- وقفه 60 ثانیه بین batch ها
- وقفه 1 ثانیه بین درخواست‌ها
- تشخیص خودکار محدودیت API

### **Retry Logic:**
- تلاش مجدد در صورت خطا
- تغییر به API پشتیبان
- ذخیره آمار خطاها

### **Backup Strategy:**
- CMC API (اولویت اول)
- CoinGecko API (پشتیبان)
- ذخیره partial data در صورت خطا
