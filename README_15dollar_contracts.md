# 🔍 Ethereum Smart Contracts Finder - $15+ Creation Cost

جستجوگر قراردادهای هوشمند اتریوم با هزینه ساخت بالای 15 دلار

## 📋 توضیحات

این ابزار قراردادهای هوشمند اتریوم را که در بازه زمانی **01-08-2025 تا 31-08-2025** ساخته شده‌اند و هزینه ساخت آن‌ها بالای **15 دلار** بوده است، پیدا می‌کند و لیست می‌کند.

## 🎯 ویژگی‌های کلیدی

### ✅ فیلتر زمانی دقیق
- بازه زمانی: 01-08-2025 تا 31-08-2025
- استفاده از timestamp برای دقت بالا

### ✅ فیلتر هزینه
- حد آستانه: 15 دلار آمریکا
- محاسبه بر اساس gas used × gas price × قیمت ETH

### ✅ اطلاعات کامل قرارداد
- آدرس قرارداد
- آدرس سازنده
- تاریخ و زمان دقیق ساخت
- هزینه ساخت (ETH و USD)
- وضعیت تایید (Verified)
- نام قرارداد (در صورت تایید)
- اندازه کد
- جزئیات تکنیکی

### ✅ منابع داده معتبر
- **Etherscan.io API**: برای اطلاعات بلاکچین
- **CoinGecko API**: برای قیمت ETH به USD

## 📈 عملکرد و محدودیت‌ها

### ⚡ سرعت
- **زمان تقریبی**: 10-30 دقیقه (بسته به تعداد تراکنش‌ها)
- **Rate Limit**: 5 درخواست در ثانیه برای Etherscan
- **بهینه‌سازی**: استفاده از chunking و caching

### 🔒 محدودیت‌ها
- **API Limits**: محدودیت تعداد درخواست Etherscan
- **دقت زمانی**: بر اساس timestamp بلاک‌ها
- **قیمت ETH**: قیمت فعلی برای محاسبه تاریخی

### 📊 دقت
- **بلاک‌ها**: اسکن دقیق بر اساس timestamp
- **هزینه**: محاسبه دقیق gas × gas price × قیمت ETH
- **تایید**: بررسی وضعیت verify از Etherscan

## 🛠️ عیب‌یابی

### خطاهای رایج

#### 1. خطای API Key
```
❌ خطا: Invalid API Key
```
**راه‌حل**: 
- بررسی کلید API در فایل `.env`
- دریافت کلید جدید از etherscan.io

#### 2. خطای Rate Limit
```
❌ خطا: Rate limit exceeded
```
**راه‌حل**: 
- صبر چند دقیقه
- کاهش سرعت درخواست‌ها

#### 3. خطای اتصال
```
❌ خطا در دریافت قیمت ETH
```
**راه‌حل**: 
- بررسی اتصال اینترنت
- استفاده از VPN در صورت فیلتر بودن

### لاگ‌ها
تمام خطاها و پیام‌های مهم در کنسول نمایش داده می‌شوند.
